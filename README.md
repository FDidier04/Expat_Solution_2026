# ExpatSolutions

Site vitrine bilingue d'ExpatSolutions, une entreprise spécialisée dans
l'accompagnement des expatriés et des entrepreneurs en République du Congo.

## Fonctionnalités

- Présentation des expertises et de la démarche
- Visuels de Brazzaville, des Tours Jumelles et du viaduc
- Interface responsive
- Navigation français / anglais
- Animations au défilement
- Coordonnées Congo et France

## Ouvrir le site

Ouvrez simplement `index.html` dans un navigateur.

Le projet est un site statique sans dépendances et peut être publié directement
avec GitHub Pages.
